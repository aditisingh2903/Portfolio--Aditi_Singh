# Aditi Singh — Personal Portfolio

A modern, full-stack personal portfolio built with **React + Vite**, **Tailwind CSS**, **Node.js**, **Express.js**, **MongoDB Atlas**, **Cloudinary**, and **Framer Motion**.

This project serves as my personal portfolio website, where I showcase my projects, skills, achievements, education, certifications, and professional experience through a custom-built content management system.

> **Note:** This repository is shared for portfolio and learning purposes only. It is **not intended to be used as a template, starter project, or redistributed**.

---

## ✨ Features

### Public Website

* Animated Hero section with particle effects and role typewriter
* Smooth scrolling with custom cursor and scroll progress indicator
* Premium dark UI with responsive design
* Framer Motion page and section animations
* About, Skills, Projects, Experience, Education, Achievements, Research, Certifications, and Contact sections
* Contact form with database integration
* Floating AI chatbot powered by portfolio content
* Resume download
* SEO optimization and social sharing support

### Admin Dashboard

A secure admin panel used to manage portfolio content.

Features include:

* Secure JWT authentication
* Edit profile and about information
* Manage projects, skills, experience, education, certifications, research, and achievements
* Publish/unpublish content
* Reorder portfolio sections
* Upload images and resume through Cloudinary
* View contact form submissions

### Security

* JWT Authentication
* Password hashing with bcrypt
* Helmet security headers
* Rate limiting
* Input validation
* Environment variable configuration
* Protected admin routes
